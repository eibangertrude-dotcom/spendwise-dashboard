# SpendWise — Interactive Budget Tracker

## 1. Project Description

SpendWise is a personal budgeting application built using HTML, CSS, and JavaScript. It helps users record expenses, monitor monthly spending, track their remaining budget, and make better budgeting decisions.

The project demonstrates how JavaScript can make a website interactive through decision-making, arrays, loops, DOM manipulation, and event listeners.

## 2. Features

- Set and update a monthly budget.
- Add expenses with a name, amount, category, and date.
- View monthly budget, total expenses, and remaining balance.
- Monitor budget progress and receive spending warnings.
- Display expense records dynamically in a table.
- Filter expenses by category.
- Delete individual expense records.
- View spending totals by category.
- Save budget and expense records using browser localStorage.
- Validate user input.
- Responsive layout for different screen sizes.

## 3. Technologies Used

- HTML5 — webpage structure.
- CSS3 — styling and responsive design.
- JavaScript — application logic and interactivity.
- DOM API — dynamic webpage updates.
- Browser localStorage API — local data persistence.
- Git and GitHub — version control and project hosting.
- Netlify — website deployment and hosting.
- Visual Studio Code — development environment.

## 6. Deployment Process Summary

The project was prepared and organized in Visual Studio Code before being uploaded to GitHub.

The deployment process involved:

1. Organizing the project files, including `index.html`, `style.css`, `script.js`, and `README.md`.
2. Creating and using a GitHub repository to host the project source code.
3. Connecting the GitHub repository to Netlify.
4. Deploying the website through Netlify.
5. Using the Netlify-generated website URL to access the live application.
6. Configuring the GitHub-to-Netlify connection for continuous deployment.

Changes pushed to the connected production branch can trigger automatic deployments on Netlify.

## 7. Challenges Encountered During Deployment

Some of the important challenges and areas requiring attention during deployment included:

1. **Project organization:** Ensuring all required HTML, CSS, and JavaScript files were included in the repository.
2. **GitHub integration:** Connecting the correct GitHub repository to Netlify.
3. **Deployment verification:** Confirming that the deployed website loaded correctly.
4. **Data persistence:** Understanding that browser localStorage stores data locally rather than in a shared online database.
5. **Continuous deployment:** Understanding how changes pushed to GitHub can trigger a new Netlify deployment.

## 9. How to Run the Project Locally

1. Clone the GitHub repository:

   `git clone https://github.com/eibangertrude-dotcom/spendwise-dashboard.git`

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser or use the VS Code Live Server extension.
4. Set a monthly budget.
5. Add expenses and explore the dashboard features.
